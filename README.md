# Enhanced Block Entities — Build Lag-Free Storage Rooms

Enhanced Block Entities 9minecraft Mod optimizes how the game draws items like chests, beds, and signs on your screen. In normal Minecraft, a room full of chests causes the game to slow down and stutter because it draws every single chest one by one. This mod changes how these blocks load so they draw together with the rest of the world. Your frame rate stays smooth even when you stand in a massive storage room. It is a great choice for players with older computers or huge bases.

## What this build is

An unofficial rebuild of **FoundationGames**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
